# 00 - Pi 概述与文档导航

> 来源：https://pi.dev/docs/latest

## Pi 是什么

Pi 是一个 **minimal terminal coding harness**——跑在终端里的编码 agent harness。设计原则：核心保持最小，能力通过 TypeScript extensions、skills、prompt templates、themes 和 pi packages 扩展。

由 Earendil Inc. 与贡献者维护，MIT License，源码托管在 GitHub。

## 快速接入路径

最小可用步骤：

```bash
npm install -g --ignore-scripts @earendil-works/pi-coding-agent
cd /path/to/project
pi
```

进入 Pi 后用 `/login` 完成订阅类认证，或者启动前设环境变量（如 `ANTHROPIC_API_KEY`）走 API key。详见 [[01-Quickstart-安装与首次会话]]。
