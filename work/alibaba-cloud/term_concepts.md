# 日常工作术语表

记录日常工作中遇到的专业术语，方便查阅和持续补充。新增术语时，在表格末尾添加一行即可。


| 术语                   | 解释                                                     |
| -------------------- | ------------------------------------------------------ |
| Sales Pipeline（销售管线） | 销售管理术语，指手上正在推进的生意，以及每笔生意谈到哪一步了。常见于企业对企业的销售，例如云服务、软件授权。 |
