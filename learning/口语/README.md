# 英语口语音频转写整理规范

以后整理英语口语音频转写时，统一遵循以下要求：

1. 直接沉淀正确版本，只保留正确、自然、实用的美式英语表达。
2. 自动纠正音频转写中的 ASR 识别错误，不展示错误版本，也不展示纠错过程。
3. 按实际使用场景分类整理，内容应适合直接学习和复习。
4. 涉及基本口语句型时，给出英语句型和中文解释。
5. 句型中可替换、可复用的通用组成使用粗体标出。
6. 每个知识点尽量包含：
   - 通用句型或常用表达
   - 中文解释
   - 例句
   - 常用回答
7. 必要时补充重点词汇、短语、发音或使用注意事项；没有必要时不强行添加。
8. 避免内容重复，不额外添加“核心句型汇总”“建议背诵表达”等与正文重复的章节。
9. 删除课程宣传、冗余讲解、与学习目标无关的延伸内容。
10. 使用清晰、简洁的 Markdown 排版，确保内容可以直接复制到 Obsidian，便于长期积累和复习。
11. 新增内容前先检查是否已有相同或高度相关的主题；同主题使用不同中英文标题时（如“问路”“Asking for Directions”“ask for route”），优先合并到同一处，不重复创建章节。
12. 合并内容时去除重复句型和例句，并统一章节层级、编号与表达方式。
13. 原始音频、课程字幕和 ASR 转录仅作为整理素材，不要求忠实复刻；只沉淀经纠错后最终正确、自然、高频的美式英语版本。
14. 不保留错误表达、错误版本、纠错过程、课程废话、故事、广告、重复复习录音或与学习目标无关的内容。
